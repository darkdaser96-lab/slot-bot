# slot-bot

Telegram-бот записи на услугу **без нейросети и без базы**. Работает как вебхук на Vercel. Есть простая лендинг-страница со ссылкой на бота.

## Как работает

1. `/start` — короткое приветствие и постоянная кнопка **«Записаться»**.
2. Выбор **услуги**: Замер / Ремонт / Консультация.
3. Выбор **дня** — три ближайших рабочих дня (пн–пт, Europe/Moscow).
4. Выбор **времени**: 11:00 / 14:00 / 16:00 / 18:00.
5. **Имя** → **телефон**.
6. Готовая запись уходит в `ADMIN_CHAT_ID`.
7. Состояние диалога — **в памяти** процесса (демо; слоты друг друга не блокируют).

Отмена: `/cancel`.

## Сайт

Лендинг: https://slot-bot-seven.vercel.app

Кнопка ведёт на https://t.me/servregistration_bot

## Вебхук

`https://slot-bot-seven.vercel.app/api/bot`

- **POST** — апдейты от Telegram.
- **GET** — регистрирует вебхук через `setWebhook` (токен из env).

```bash
curl https://slot-bot-seven.vercel.app/api/bot
```

## Переменные окружения (Vercel)

| Имя | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_CHAT_ID` | chat id, куда слать записи |
| `WEBHOOK_URL` | (опционально) публичный URL вебхука |

Ключи **не** кладутся в Git.
